# SimpleLive

一键转存b站的音频到网易云音乐的网盘

## 使用

demo: https://bili-music-transfer.vercel.app/

使用ffmpeg在浏览器完成格式转换和元信息写入。
如登录了网易云可以自动上传到云盘。
如有安全顾虑可以选择本地部署网易云api或者保存转换好的文件手动上传
